# Engineering Constraints

1. **Stack**: Next.js 16 (App Router), React 19, Tailwind CSS 4.
2. **Database**: Currently MongoDB (planning migration to Firestore).
3. **No Unnecessary Dependencies**: Use native Web APIs over external dependencies.
4. **Performance**: Server Components by default. Client Components only for interactions/hooks.
5. **UI/UX**: Radix UI primitives. Follow strict 48x48px touch target accessibility.
